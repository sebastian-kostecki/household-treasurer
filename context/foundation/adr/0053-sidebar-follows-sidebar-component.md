# The sidebar and the product mark follow the Sidebar component

The sidebar (`AppSidebar.vue` and its slots `AppLogo`, `BudgetYearSwitcher`, `NavMain`, `NavUser`, `UserInfo`) goes back to the `Sidebar` component of the "C · Atrament i morski" design system (artifact https://claude.ai/artifact/9gJSdtfpFgUAa8oEMgR4HA, `project/components/Sidebar/README.md` and the `.ht-side*` classes), as it stands on 2026-11-06. The view kept the 16rem width of the starter kit, section labels composed by hand, no `aria-current`, a square 32 px avatar on `muted` without the e-mail and a temporary `Vault` glyph in place of the product mark. This ADR records where the sidebar follows the component and where it departs from it, and from earlier ADRs.

Width. The desktop width is the token `--sidebar-panel-width` (224 px) in `app.css`, not `--sidebar-width`: `SidebarProvider` writes `--sidebar-width` inline on its wrapper, so a token with that name in `:root` would lose to the inline style, and `SIDEBAR_WIDTH = "var(--sidebar-width)"` would point at itself (the same reason as `--dialog-shadow` in ADR-0040). The icon strip stays 3rem and the mobile sheet stays 18rem, because the component does not define a mobile width. The figures in ADR-0051, paragraph 3 ("16rem sidebar"), describe the old width; the `xl` decision there stands.

Shell primitives. The sidebar is the whole shell of the app, not one screen, so this change edits `ui/sidebar/utils.ts` (width from the token), the `cva` in `ui/sidebar/index.ts` (`rounded-md` and `font-semibold` for the active item, replacing `rounded-xl` and `font-medium`) and `SidebarGroupLabel.vue` (`label-caps` in the base classes, not through `class`, because `cn` does not know that the named utility collides with `text-xs` and `font-medium`). The precedent is `design-tokens-atrament`, which changed the same `cva`. A later shadcn-vue update will overwrite these rows; this ADR names them.

Section labels. "Rok budżetu" stands above the year switcher and "Menu" above the list, both `label-caps` in `sidebar-foreground` (in line with ADR-0037, paragraph 1: capitals only over measures and in the sidebar). The year button shows the year alone; the empty state "Brak roku budżetu" is a second line in the `meta` style. In the icon strip the labels disappear and the tooltip of the year stays.

Current page. The link of the current section carries `aria-current="page"`, set from the same `isCurrentSection` that sets `is-active`, so a sub-page such as `/operations/import` keeps "Operacje" both highlighted and announced. Inertia's `Link` does not add the attribute; the precedent for setting it by hand is `layouts/settings/Layout.vue` (ADR-0049).

User block. In the sidebar the avatar is round, 28 px, on `sidebar-accent`; the name is `sidebar-strong` and the e-mail under it is `sidebar-foreground`. `UserInfo` takes `variant="sidebar"` for it. The avatar is round also in the user menu (`UserMenuContent`), so the product has one shape of avatar; the rest of that menu does not change.

Brand mark. The mark is "HT" in JetBrains Mono 600, 11 px, on `brand`, in a 26 px tile with `radius-sm`, one size everywhere, always with the name of the product next to it. It is the component `BrandMark` and the named style `brand-mark` with the size token `--brand-mark-size`. It stands in the sidebar, above the login card (the mark and the name, the link has an accessible name) and in the header and the footer of `Welcome`. It replaces `Vault` and so closes C5a deferred by `sidebar-ui-contract`. It extends the sentence of ADR-0035 that JetBrains Mono is the face "for amounts" without replacing it, as `mark-label` did for bank marks (ADR-0047). The unused starter-kit files `AuthSimpleLayout`, `AuthSplitLayout`, `AppHeader`, `AppHeaderLayout` and `AppLogoIcon` are removed. `LandingAppPreview.vue` keeps its decorative tile, because it is an illustration, not the product mark.

We rejected the command palette ⌘K and the shortcuts `1`–`6`, `N` and `/` (a separate change `command-palette`: a new component, global key handling and a new prop), the year in segments (they do not fit the 3rem strip, the number of years grows without a limit and "2027 +" mixes choosing with creating), a second size of the mark (the design system gives one value) and styles on the consumers of `SidebarProvider` (the width and the item shape belong to the primitives). It changes no rule in `context/foundation/glossary.md` and no _Avoid_ term, and it changes no Inertia prop.

Superseded in part by ADR-0059: the mark is "HT" in JetBrains Mono on a text tile, "not an image". The mark is a drawing of a house with a coin in the `brand` tile; the size, the radius and the rule "always with the name" stay.
