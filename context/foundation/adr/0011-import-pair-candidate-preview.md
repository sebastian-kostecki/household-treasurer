# Import pair candidate is a distinct opt-in preview overlay

An Import pair candidate stays a valid preview row, distinct from Import duplicate and from invalid (invalid wins). Every row starts unchecked; checking is the opt-in. A Financial Operation–only set is classifiable (unique candidate prefills Own Transfer and that Account; another Account is a new Own Transfer, not a pair). Any Own Transfer in the set locks type to Own Transfer and offers only those transfers — booking income or expense would move the preview Account again. The other-account slot is today’s active Account list plus first-leg Accounts of candidates (archived only as a pair target). A selected row consumes its first-leg in this preview; commit allows at most one pair per first-leg. The rest of the file still commits. We rejected pre-checking pairs, mixing pair with Import duplicate, closest-date auto-pick, a second acknowledgement checkbox, and converting a Financial Operation when an Own Transfer already moved the preview Account.
