# "Domowy Skarbnik" and the house-with-a-coin mark

The product is named in Polish and its mark is a drawing, not the letters "HT". The UI copy is Polish, and "HT" stood for the English working name Household Treasurer, so the tile said nothing to the user. The repository keeps the English domain language in code and agent docs (`AGENTS.md`); the name the user sees is "Domowy Skarbnik".

Mark. `BrandMark` is a `brand` tile of 26 px (`--brand-mark-size`) with `radius-sm`, as before, and inside it an inline SVG that uses `currentColor`, which is `brand-foreground`. The drawing is the outline of a house (roof and walls) with the disc of a coin in the middle, legible at 16 px, with stroke and no fine detail. The component keeps its name `BrandMark` and the named style `brand-mark` stays in `app.css`, now as the tile without a typeface. The rule "always with the name of the product next to it" (ADR-0057) stays. The ban on Lucide icons in the role of the mark stays, because the drawing is our own.

Files in `public/`. The favicon (SVG and ICO) and `apple-touch-icon.png` (180 x 180) carry the same drawing, with the hex values of `brand` and `brand-foreground`. They are static assets outside the views and cannot read tokens, so the values are copied once and a change of the tokens means regenerating them. `site.webmanifest` and `theme-color` are not part of this decision.

Name and identifiers. The visible name flows from `APP_NAME` and `VITE_APP_NAME`: page titles, the landing, the footer of the entry screens, the 2FA issuer (the issuer changes only for new QR codes; entries already in authenticator apps keep working) and the strings that were written in `lang/pl/ui.php`. The identifiers of infrastructure no longer follow `APP_NAME`. The session cookie, the cache prefix, the Redis prefix and the backup name (and the name of its monitor) get constant defaults in `config/`, equal to what the old name produced (`household-treasurer-session`, `household-treasurer-cache-`, `household-treasurer-database-`, `Household Treasurer`), so renaming the product neither logs anyone out, nor orphans the cache, nor moves the backup directory. A production `.env` with a different `APP_NAME` sets `SESSION_COOKIE`, `CACHE_PREFIX` and `BACKUP_NAME` explicitly before the deploy, and the production image is rebuilt, because `VITE_APP_NAME` is baked into the bundle at build time. The database `household_treasurer`, the backup directory `/storage/household-treasurer-backups`, the image tag, the Sail network, the package name and the names of classes and files in code stay.

This supersedes in part ADR-0053 (the mark is "HT" in JetBrains Mono on a text tile, "not an image") and ADR-0057 (the sentence on the product mark of the landing preview, now that the mark is the drawing; the rule "always with the name" and the ADR-0053 sentence it narrows stay). It changes no rule in `context/foundation/glossary.md` and no _Avoid_ term, adds no token and no Inertia prop.

We rejected the monogram "DS" (hard to read at 16 px and not an icon) and a piggy bank (says less about a home and has too much detail at 16 px).
