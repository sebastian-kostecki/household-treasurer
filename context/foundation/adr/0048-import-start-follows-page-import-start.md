# Import step 1 follows the design system card PageImportStart

Step 1 of the Import ("Import operacji", `OperationsImport.vue`) goes back to the "C · Atrament i morski" design system (artifact https://claude.ai/artifact/9gJSdtfpFgUAa8oEMgR4HA): the card `PageImportStart` is the reference, as it stands on 2026-11-06. The view was built before Atrament, so it carried its own title size, a bare `Card` and hand-made blocks. The design system had no recipe for a form that lives on a page and not in a dialog, so this ADR adds one instead of letting the view invent it. Step 2 (`/dev/import-preview`) is not restyled here.

Form panel. A form on a page stands in a panel of the width `--form-panel-width`, a token of 640 px in `resources/css/app.css`. The panel is a `card` with a full `border` and `rounded-lg` and no shadow (ADR-0037). It has three named parts: `.form-panel-header` (`h2.section-title` and a `p.meta` line, which depends on the chosen Import format), `.form-panel-body` and `.form-panel-footer` (a border on top, the main action to the right). "Pokaż podgląd" lives in the footer, with a spinner while the request is sent, and not in the body.

Title row. The page builds the title row from `page-title`, the description of the step in `meta`, and the exit "Wróć do operacji" as `outline` with `ArrowLeft`, the same as step 2. ADR-0045 keeps `ghost` for "Anuluj"; "Wróć do operacji" is a navigation to another page, not a way out of a form, so it stays `outline`.

Fields. `FormField` (ADR-0040) applies to a form on a page as well, not only in a dialog: label, control, hint and error linked by `aria-describedby`, at 34 px. A field that the server validates shows its error there, including `has_header` and `amount_layout`. "Rozpoznawane pola" is the existing `.form-preview` block with the list `.form-preview-list`, not a bordered `list-disc` made by hand. A checkbox row is `.form-check-row`. A group of fields ("Kolumny") is a `fieldset.form-fieldset` with a `legend.section-title` and no frame of its own, so there is no card inside a card. The choice of the amount layout is a `SegmentedControl` with `block`, tone `primary` and a `name` (ADR-0041 form rule), not raw radio inputs.

No active Account. When the user has no active Account, the panel shows `IndexEmptyState` with a link to Konta instead of the form. The form with a disabled button and no reason is gone.

Format and columns. The extension of the chosen file sets the Import format only while the user has not chosen the format by hand; a hand choice, such as "Inny", is never overwritten. A change of the format to "Inny" recalculates the columns from the file that is loaded now, so indexes of a previous file do not survive. This adds to ADR-0002 (the guess of the format from the file stays) and does not change ADR-0004 (the Bank of an Account does not select the Import format). `has_header` travels in an explicit hidden input, so that the value `0` reaches the server; the `Checkbox` has no `name`.

We rejected `ListSurface flush` with its own footer (`#footer` with no `border-t`): a form is not a list and the footer would need the border redone by hand. We rejected `max-w-xl` and `max-w-2xl` (576 and 672 px, neither is 640). We rejected removing the guess of the format, because it saves a click for the two known banks and the fault was the overwrite, not the guess. We rejected `ghost` for "Wróć do operacji" (it would differ from step 2 and hide a navigation among the cancel actions).
