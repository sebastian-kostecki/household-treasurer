# Cross-Import pair match is frozen amount, opposite sign, and a three-day date window

A later Import row is an Import pair candidate when it belongs to this User, sits on a different Account than an existing Import-born Financial Operation or one-identity Own Transfer, the frozen signed file amounts are exact opposite grosze, and the frozen file calendar dates fall within three days inclusive. We match the frozen Import identity, not live date, amount, or Account. We ignore Opis phrases and Import format: there is no bank transaction id, mBank “wewnętrzny” is not this User, and Other format has no token. Cash Accounts and a later-archived first-leg Account still participate; hand-entered and null-fingerprint records do not. The predicate returns a set — several candidates stay candidates. We rejected exact-date-only (misses Elixir T+1 and weekends), a money window (fees are other rows), requiring phrases, unique-or-nothing, closest-date auto-pick, and a special ATM matcher.
