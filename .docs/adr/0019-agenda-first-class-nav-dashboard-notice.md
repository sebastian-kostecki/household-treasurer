# Agenda is a first-class nav home; Dashboard only notices

Cash Expectations are created, listed, and settled on Agenda, a new top-level nav item after Operations. Dashboard shows overdue and today by calendar date (any year) as notice only: no create, no settle, no nav badge. Opening a notice row switches the shell Budget year to that Cash Expectation’s date year and opens Agenda. Agenda itself follows the shell year, like Budget.

We rejected putting unpaid rows on Operations or Budget (they are not Financial Operations and they do not earmark Available Limit), a Dashboard workspace, and an overdue badge that would disagree with either the shell year or the notice list.
