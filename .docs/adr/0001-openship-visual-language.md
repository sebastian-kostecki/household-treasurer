# OpenShip visual language on shadcn-vue

Household Treasurer is a light-default household budget app, not a deploy console, but we still take Openship’s dense sidebar-and-cards language (teal primary `#0b7285`, compact desktop, looser mobile) and reimplement it in the Laravel Vue starter’s Tailwind + shadcn-vue tokens. We do not fork Openship’s Next.js dashboard or `@repo/ui`. Light is the default because the persona is home finance; dark keeps the same tokens. Fonts stay on the starter stack so the “look” is colour and density, not a second type system.
