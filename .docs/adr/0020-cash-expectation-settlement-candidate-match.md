# Cash Expectation settlement candidates match Account, type, exact amount, and a 31-day window

A Cash Expectation is a settlement candidate for an Import preview row, and a Financial Operation is a settlement candidate when attaching from a Cash Expectation, when they share this User, Account, and type family (income / expense / expense refund), the amounts are equal in the Financial Operation convention (exact Minor units; a file debit matches a positive expense), and the Cash Expectation date and the file date (preview) or live Financial Operation date (attach) fall within 31 inclusive calendar days. Description, Counterparty, and Category do not gate candidacy. There is no extra same-year gate: December unpaid and January paid can both sit in the window. The predicate returns a set; the User picks at most one; that pick consumes the Cash Expectation in this preview; a Financial Operation already attached is not a candidate. Import duplicate and invalid still win; pair opt-in and settlement opt-in are mutually exclusive; Own Transfer and Capital Movement never qualify. Opt-in does not overwrite file date, amount, description, Counterparty, or Raw Statement Description; Category prefills from the Cash Expectation only if the row has none and that Category is legal for the file date’s year. A stale pick clears when the row fails the predicate. We rejected auto-match, exact-date-only, ignoring date, a money window, same-year-only, unique-or-nothing, closest-date auto-pick, and rewriting the Financial Operation on attach.
