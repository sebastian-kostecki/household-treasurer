# Css

## New colours are tokens in both :root and .dark

Add --name in :root and .dark plus --color-name in @theme inline, then use it as a utility. Text colours must reach 4.5:1 on card; that is why light destructive is red-600 and warning is amber-700. Record any token change in .docs/design-system.md.
